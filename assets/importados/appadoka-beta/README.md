# SVGs oficiais — appadoka v0.0.1

Pasta reservada para os SVGs oficiais que a proprietária enviará diretamente ao GitHub. A criação desta pasta não altera as imagens nem as referências usadas pelo protótipo.

## Organização sugerida

- `logo-principal.svg`
- `logo-horizontal.svg`
- `icone-app.svg`
- `marmita.svg`
- `lanche.svg`
- `sobremesa.svg`

Esses nomes são apenas exemplos de organização; nenhum SVG foi criado ou incluído nesta preparação.

## Recebimento e uso

1. A proprietária envia os arquivos originais para esta pasta pelo GitHub.
2. Após a sincronização com o remix, conferir os arquivos recebidos e sua identificação com a proprietária.
3. Verificar proporções, cores, legibilidade e ausência de scripts ou referências externas antes de qualquer uso.
4. Propor a aplicação em um lote pequeno e aguardar aprovação humana antes de alterar as referências do protótipo.

Preservar os assets atuais em `public/brand`. Não redesenhar, converter, substituir ou modificar o material existente nesta etapa. O envio dos arquivos por si só não muda as telas.
